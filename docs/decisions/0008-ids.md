# D8. UUIDv7 for app tables; text for Better Auth ids

Status: Accepted

## Context

Ids appear in URLs and must not be guessable or reveal counts; event lists page by time.

## Decision

Use UUIDv7 for every app table (time-ordered, so it doubles as the event list cursor). Better Auth's user and session ids are text and are referenced as `text`.

## Consequences

- Non-sequential public ids and efficient time-ordered indexes.
